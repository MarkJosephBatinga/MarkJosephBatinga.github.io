How I run an engagement, step by step

If you've never hired a freelance web developer directly, here's exactly what happens — and what you should demand from anyone you hire, including me.

  1. Discovery call. 20 minutes. You describe the problem; I tell you honestly whether I'm the right fit — and if a cheaper path exists, I'll say so.
  2. Written proposal with milestones. Scope, timeline, price, and what "done" means for each milestone. No open-ended hourly black holes.

  4. Build with weekly written updates. Done / next / blockers / staging link, every week, in writing. You always know where your money went.

The two fears that stop most overseas hires are ghosting and code ownership. Here's how both are structurally impossible in my setup:

  • Copyright, in writing, first.
